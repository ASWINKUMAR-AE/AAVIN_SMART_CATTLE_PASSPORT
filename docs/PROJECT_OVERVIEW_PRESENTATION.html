🧪 The Deterministic Milk Safety Twin

4-Domain Decision Logic & Thresholds
Safety Parameter Standard Standard (CLEAR) Warning Boundary (REVIEW) Critical Rejection (HOLD)
Active Vet Withdrawal No active antibiotic restriction — Under active withholding period
Adulteration Chemical Screen Negative (0 Detected) — Positive (Urea, Starch, Detergent, Sugar)
Milk FAT % ≥ 3.50% 3.00% – 3.49% < 3.00%
Milk SNF % ≥ 8.50% 8.00% – 8.49% < 8.00%
Intake Temperature ≤ 10.0°C 10.1°C – 12.0°C > 12.0°C (Spoilage hazard)
💡 Transparent Price Formula: Rate = BaseRate (₹36.00) + [(FAT - 4.0) * 0.30] + [(SNF - 8.5) * 0.20] + QualityIncentive (₹1.00)

📊 Technical Architecture & Database Stack

📱 Frontend & Backend Stack
  • Mobile App: React Native 0.81.4, Expo SDK 54, Expo Router v6, TypeScript
  • UI Design: Cupertino grouped cards, Reanimated springs, Expo Haptics
  • Backend: Node.js Express TypeScript, Socket.IO, Helmet, Rate-Limit
  • Database Engine: MySQL via XAMPP / InnoDB, prepared queries, strict FKs
  • AI Engine: OpenRouter & Self-hosted LLM with non-silent audit fallback
🗄️ 40 Relational Tables (InnoDB)
  • Identity: users, roles, permissions, refresh_tokens
  • Passport: cows, cow_qr_tokens, cow_owner_history
  • Clinical: medicine_catalog, treatment_records, withdrawal_restrictions
  • Intake: milk_collection_records, milk_quality_tests, milk_safety_decisions
  • Logistics & Pay: milk_batches, batch_movements, farmer_payment_cycles
